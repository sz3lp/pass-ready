# Pass Ready

Study desk for **Snoqualmie Pass Fire & Rescue** students in the King County EMS EMT Program, Fall 2026.

## Jeopardy

Every lecture has a board — not just Medical Director night on Dec 7. Open **Jeopardy**, pick the class you just sat, split into two teams, host reads the stem, then Reveal / Award / Deduct.

## Run it

```bash
cd crew80
npm install
npm run dev
```

Usually [http://localhost:5173](http://localhost:5173). Progress stays in the browser.

The 80% bench (4 blocks + 5 quizzes) still gates the Dec 10 final. 70% on that test still gates the Dec 12 practical.
